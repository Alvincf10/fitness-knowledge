# Style Guide

## Language

- English only
- Concise
- Evidence-first
- No personal opinion

## Tone

- Neutral and instructional
- No hype, fear, or clickbait
- No medical diagnosis
- Explain claims through research

## Structure

- Follow the category template exactly
- Use bullets only when they improve scanability
- Keep sections focused on one job
- Always include References

## Metadata

Every article must open with YAML frontmatter, including at minimum:

- `id`
- `title`
- `category`
- `updated`
- `reviewed`
- `evidence`

Category-specific fields (muscles, equipment, tags, related topics) should be included when applicable.

## Evidence Grades

| Grade | Criteria |
|-------|----------|
| A | Strong evidence; multiple meta-analyses |
| B | Several RCTs |
| C | Limited human evidence |
| D | Expert opinion only |

## Citations

Use simple APA:

```
Schoenfeld BJ (2017)
Morton RW (2018)
ACSM Position Stand (2022)
ISSN Position Stand
NSCA Essentials
```

Prefer primary scientific sources over secondary summaries.

## Cross-Linking

End articles with Related links to connected topics, for example:

```
Related

- Progressive Overload
- Training Volume
- Chest Hypertrophy
- Incline Bench Press
```

## Tags

Use controlled tags such as:

- strength
- hypertrophy
- beginner
- intermediate
- advanced
- push
- pull
- compound
- isolation
- machine
- free-weight
- bodyweight

## Formatting

- Title as H1
- Section headings as H2
- Keep paragraphs short
- Prefer precise terms over marketing language
