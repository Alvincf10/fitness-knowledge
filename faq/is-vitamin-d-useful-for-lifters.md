# Is vitamin D useful for lifters?

## Question

Is vitamin D useful for lifters?

## Short Answer

Useful if you are deficient; not a muscle-building shortcut when levels are already adequate.

## Detailed Explanation

Test when possible. Supplementation helps deficient individuals more than already-replete ones.

## Evidence

ISSN sports-supplement position stands and systematic reviews for the specific ingredient when available. Evidence grade: B.
