# How many sets per week are enough for core growth?

## Question

How many sets per week are enough for core growth?

## Short Answer

Many intermediates grow core on roughly 10–20 hard sets per week, adjusted for recovery and exercise choice.

## Detailed Explanation

Weekly set ranges are starting points. Beginners need less; advanced lifters sometimes tolerate more. Track performance and soreness patterns.

## Evidence

Schoenfeld and related hypertrophy reviews; ACSM resistance-training position stands; NSCA programming guidance. Evidence grade: A.
