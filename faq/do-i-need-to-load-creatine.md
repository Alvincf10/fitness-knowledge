# Do I need to load creatine?

## Question

Do I need to load creatine?

## Short Answer

No. Loading speeds saturation; 3–5 g daily without loading still works in a few weeks.

## Detailed Explanation

Loading (~20 g/day briefly) saturates stores faster. Non-loading is simpler with fewer GI issues for some.

## Evidence

ISSN sports-supplement position stands and systematic reviews for the specific ingredient when available. Evidence grade: B.
