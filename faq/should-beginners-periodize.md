# Should beginners periodize?

## Question

Should beginners periodize?

## Short Answer

Simple progression is enough at first; formal periodization matters more later.

## Detailed Explanation

Novices grow on basic linear progress. Add structure when plateaus appear.

## Evidence

ACSM progressive-overload principles; periodization and autoregulation (RIR/RPE) literature. Evidence grade: A.
