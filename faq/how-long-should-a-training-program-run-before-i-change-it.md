# How long should a training program run before I change it?

## Question

How long should a training program run before I change it?

## Short Answer

Many blocks run 4–12 weeks before a deload or exercise refresh, depending on progress.

## Detailed Explanation

Change when progress stalls for weeks despite recovery, not because of boredom alone.

## Evidence

ACSM progressive-overload principles; periodization and autoregulation (RIR/RPE) literature. Evidence grade: A.
