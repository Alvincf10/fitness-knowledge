# Can I replace the Romanian Deadlift if it hurts?

## Question

Can I replace the Romanian Deadlift if it hurts?

## Short Answer

Yes. Swap to a pain-free variation that trains a similar pattern and can still be overloaded.

## Detailed Explanation

Exercise selection is a tool. Pattern continuity matters more than any single named lift.

## Evidence

NSCA technique standards and biomechanics principles; individual anthropometry changes optimal form details. Evidence grade: B.
